# KINEXIS Connect asset package

## Included
- 29 transparent illustration/icon/sticker SVG files: hero, desktop/mobile workflow, CTA, authentication panel, five onboarding illustrations, eight feature icons, eight empty states and three plan stickers.
- Brand package: supplied original WebP; traced horizontal SVG, dark and white SVG/WebP; monogram SVG/512 PNG; favicon SVG/ICO/16/32 PNG; 180/192/512 app icons and maskable 512 PNG; 480×160 transparent email logo; 1200×630 social PNG/WebP plus editable SVG.
- Contact sheet and self-contained local asset gallery (open asset-gallery.html with the folder intact).

## Brand source and limitations
The supplied Kinexis_Connect_Logo.webp is preserved unchanged. The SVGs are reconstructed from its flat-color shapes, not the original design vector. Small compression artifacts and minor edge differences may remain. White uses white lettering/fills with the reference black sticker keylines, suited to dark backgrounds; dark replaces the white sticker border with navy for light backgrounds. The monogram redraws the reference K without the surrounding wordmark; inspect favicon recognition in the actual browser before release. Social image copy is editable in its SVG; its typography is a substitute, not the missing approved Poppins/Inter font files.

## Integration
Copy public/assets/connect into your project's public/assets directory. Reference assets as /assets/connect/illustrations/connect-hero-flow.svg, etc. Use missed-call-workflow.svg above 768 px and missed-call-workflow-mobile.svg below. Both variants use pictograms without embedded marketing copy; provide the four stage headings in HTML. Set decorative img elements to alt=""; meaningful images need context-specific alt text. SVG titles provide fallback descriptions. Pricing tiers and prices stay in HTML; Professional has an orange featured star. Empty-state SVGs reserve their lower area for surrounding interface copy.

Palette: navy #101D3A, cobalt #0062FF, orange #FF7900, cyan #65DCEB, pale #EDF3FF. Illustration navy is provisional because the live-site source tokens were unavailable. Feature icons use a 96×96 viewBox and 3.5-unit strokes. All artwork is vector-native and independent of a font except the editable social card copy.
